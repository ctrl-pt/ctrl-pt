# Visual component provenance

- SVG tool icons: [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons), fetched October 12, 2026. Its MIT license is retained in `skill-icons-LICENSE`.
- Contribution snakes: generated using [Platane/snk](https://github.com/Platane/snk), through the official `generate-snake-animation` npm package, version 3.5.0. Its repository and npm package did not include a LICENSE file at review. The upstream README expressly documents generating profile SVG/GIF outputs. This package includes generated output, not the upstream implementation.
- All other hero graphics, metrics boards, build symbols, charts, heatmaps, and section artwork were authored for ctrl-pt.
- Other personal profiles were used for design research only. Their personal artwork, portraits, and biographies are not included.
